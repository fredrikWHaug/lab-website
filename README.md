# Svelte Project

A minimal and streamlined Svelte project setup.

## Setup

To set up the project locally: Clone the repository using `git clone <repository-url>`, then navigate to the frontend directory using `cd frontend`, and finally install the dependencies using `npm install`.

## Development

To start the development server, run `npm run dev`. For automatically opening the app in your default browser, use `npm run dev -- --open`.

## Build for Production

To create a production build of the project, run `npm run build`. You can preview the production build locally by running `npm run preview`.

## Notes

Ensure you have Node.js and npm installed on your machine. This project uses Svelte for the frontend.
